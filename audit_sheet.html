Random Audit: apni aankhon se tasalli

Kaise karna hai (har item ke liye):
  1. Item mein likha PDF ka naam dhoondo (STAGE_1/data folder) aur Chrome mein kholo.
  2. Page number par jao. Na mile to 1-2 page pehle dekho (chunk ka page kabhi 1-2 aage hota hai).
  3. Neeche wala tukda PDF mein dhoondo (Ctrl+F mein kuch alfaaz likh kar bhi mil jata hai).
  4. Table ho: pehli 4 rows ke numbers PDF se milao. Text ho: shuruaat aur aakhir ke jumle milao, aur dekho text kata ya garbled to nahi.
  5. Button dabao: S = sahi, T = thora ghalat (number sahi, label/naam thora off), G = ghalat (number ghalat ya gayab, ya text kata hua). Jo S nahi, uski ek line note mein likho.
Tumhara kiya hua is page mein khud save hota rehta hai (isi computer ke Chrome mein). Band karke baad mein dobara kholo to wahin se jaari.
